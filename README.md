# MyFirstWebAPI

API для управления книгами на ASP.NET Core.

## Технологии
- C# / .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

## Что умеет
- GET /Books — список всех книг
- GET /Books/{id} — одна книга
- POST /Books — добавить книгу
- PUT /Books/{id} — обновить книгу
- DELETE /Books/{id} — удалить книгу
- GET /Books/search?author= — поиск по автору

## Как запустить
1. Клонировать репозиторий
2. Открыть в Visual Studio
3. Запустить `Update-Database`
4. Нажать F5
