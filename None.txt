Code 200 — код ответа. 200 означает «ОК, всё хорошо».

Response body — данные, которые вернул сервер. Это JSON — формат, в котором программы обмениваются данными.

Response headers — служебная информация. content-type: application/json говорит, что данные в формате JSON.

Папка Controllers: В ней лежит готовый контроллер WeatherForecastController. Это пример того, как выглядит код, который обрабатывает запросы.

Файл Program.cs: Это «мозг» приложения. Там настраивается сервер и говорится, какие контроллеры использовать.

[Route("[controller]")]	[Route("Books")]
Автоматически подставляет имя	Явно указывает путь
Может конфликтовать с моделями	Всегда работает
Короче	Понятнее
Явный маршрут — это нормально. В реальных проектах часто пишут [Route("api/books")] — так надёжнее.
Клиент видит только то что ты возвращаешь через RETURN
void - ничего не возвращает, он просто выполняет действие внутри себя. Поэтому в Swagger пишеться в Header Response content-length: 0
